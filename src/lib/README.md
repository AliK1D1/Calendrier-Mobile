# `src/lib/` : logique partagée avec le site

Ce dossier est une **copie** du `src/lib/` du site (dépôt `AliK1D1/calendrier`), faite par
`npm run sync:web -- <chemin du dépôt du site>`. Ne pas modifier ces fichiers ici : corriger
le site, puis relancer la synchro.

Seuls `actions.ts` et ce README sont propres au mobile.
